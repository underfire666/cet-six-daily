# 六级日常 · CET-6 学习首页原型

面向大学生的每日六级学习原型，以完整月历、按日期解锁与立体关卡为核心。仅实现第一阶段：首页和功能占位页。

## 本地运行

项目目录：`E:\The king of CET`

```powershell
Set-Location 'E:\The king of CET'
npm ci
npm run dev
```

依赖已安装时直接运行 `npm run dev`。默认访问 <http://127.0.0.1:3000>。端口占用时可运行 `npm run dev -- --port 3001`，以终端输出为准。服务器仅绑定本机，不对局域网开放。

```powershell
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

生产服务与开发服务默认使用相同端口，运行 `npm start` 前先停止开发服务。npm 缓存保存在项目的 `.npm-cache`，不需要修改系统目录权限。

## 技术栈

Next.js 16.3.5（App Router）、React 19.3.0、TypeScript 6.0.3、Tailwind CSS 4.3.3、Lucide 图标。依赖版本固定，`package-lock.json` 用于可重复安装。已在 Node.js 24.15.0、npm 11.12.1 下验证。

## 已实现

- 顶部连续学习、等级与经验进度；真实计算的六级倒计时。
- 周一开头的完整月历、前后月切换、回到今天。
- 今天、已完成、已调整、未解锁四种状态；今天标记独立于选中状态。
- 日期与关卡曲线连接，选择日期更新任务、时长和学习模块。
- 今日开始、历史重练、调整后计划跳转、未来计划禁用。
- 学习页返回后保留日期；选中日期写入 URL，刷新可恢复。
- 直接访问未来学习路由仍被锁定，无效日期或专项返回友好的未找到页面。
- 五项专项练习与学习／AI／我的导航均可使用。
- 手机与桌面响应式布局，键盘焦点、日期状态标签、减少动效设置。

## Mock 范围与日期约定

- 用户：一翔；连续 7 天；Lv.12 · 进阶者；1240 / 1500 XP。
- 考试日期固定为 **2026-12-11**，是实施日 2026-09-15 之后 87 天，**不是官方考试日期**。在 `src/data/mock.ts` 修改；刷新不会重设目标日期。
- 当前日期按 `Asia/Shanghai` 计算；页面每秒及重新聚焦时检查跨日，首屏共享服务器日期以避免 hydration 不一致。
- 最近 7 个历史日固定显示完成，更早日期按确定性规则展示完成或调整；今天默认 14 分钟、词汇／阅读／听力。
- 未来日期按时间锁定。调整目标是演示数据，没有自动补课算法。
- 学习与重练仅进入占位页，不改变 XP、连续天数和完成状态；不保存真实学习记录。
- 考试当天与目标过期分别提供提示，不显示负数倒计时。

## 修改视觉

`src/app/globals.css` 中的 `:root` 集中定义 primary、background、surface、text、muted、success、warning、border、圆角与阴影。只提供浅色模式。品牌图标为原创 SVG，无多邻国品牌素材，无外部字体或远程图片依赖。
