## 一、本轮（v12repair4）完成项

### 1. Domain → Sync Queue（P1-A）
- **XP Event**：`LearningProvider.awardXp` 在本地写 profile 后调 `enqueueXpEvent`，source 从 eventId 前缀推断（vocabulary/reading/listening/review/...）
- **Learning Session**：`LearningProvider.dispatch` 完成 session 后调 `enqueueSession`（含 planDate/startedAt/completedAt/status）
- **Wordbook**：`VocabularyProvider.toggleWordbook` 调 `enqueueWordbook`（add=upsert / remove=tombstone）
- **Settings**：`LearningProvider.setSettings` 调 `enqueueSettings`
- 其他 domain（Reading/Listening/Translation/Writing/Review/DailyPlan/Profile/Preferences）的 adapters 已存在，待对应 Provider 接入

### 2. Scoped Storage（P1-B）
- 新建 `src/lib/storage/scoped.ts`：`getScopedStorage()` 返回 KeyStorage wrapper
  - guest：legacy key（`cet-daily:*`）
  - user：`user:<id>:cet-daily:*`
- `VocabularyProvider` 和 `LearningProvider` 已改用 `getScopedStorage()` 替代 `window.localStorage`
- AccountResetGate `key={userId}` 重挂 Provider，scope 切换自动生效

### 3. Queue user-scoped
- queue key 含 userId：`cet-daily:v12:sync-queue:<userId>`
- A 的 pending 不会被 B push

### 4. Remote hydrate 不 echo
- hydrate 直接写 localStorage，不经过 awardXp/toggleWordbook 等 mutation 函数，不会再次 enqueue

### 5. 测试
- 新增 `tests/v12-integration.test.ts`（8 条集成测试）：
  - guest enqueue no-op
  - logged-in enqueue XP event
  - queue A/B 隔离
  - wordbook add/remove merge 到 tombstone
  - review version 递增（state merge 保留最新）
  - dailyPlan completedTaskIds 并集
  - nsKey guest/user 命名空间
  - 跨 scope 数据隔离
